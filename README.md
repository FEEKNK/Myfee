# MY FEE 📚✨

**MY FEE** คือแอปพลิเคชันผู้ช่วยส่วนตัวในชีวิตประจำวัน (Personal All-in-One Life Companion) ที่สร้างขึ้นมาเพื่อตอบโจทย์การใช้งานของตัวเองเป็นหลัก ทำงานแบบ Single Page Application (SPA) ความเร็วสูง จัดเก็บข้อมูลทั้งหมดในเครื่องผ่าน LocalStorage และรองรับการใช้งานออฟไลน์ (PWA) 100%

---

## 🌟 ฟีเจอร์ปัจจุบัน (Current Features)

*   📊 **ศูนย์รวมภาพรวมชีวิต (Life Dashboard & Analytics):**
    *   หน้าแรกแบบ Hub รวมการ์ดสรุปสถานะประจำวัน: สถิติ Flashcards, งาน To-Do, ปริมาณการดื่มน้ำ, ยอดใช้จ่ายประจำวัน และการทำนิสัยประจำวัน
    *   ระบบ Quick Launcher เข้าถึงทุกเมนูได้ในสัมผัสเดียว
*   📖 **ระบบเรียนรู้คำศัพท์ (Flashcards):**
    *   เรียนรู้คำศัพท์ภาษาอังกฤษพร้อมคำอ่าน (IPA) และชนิดของคำ (Part of Speech)
    *   พลิกการ์ด 3D เพื่อดูคำแปลภาษาไทยและประโยคตัวอย่าง
    *   มีระบบออกเสียงคำศัพท์ (Text-to-Speech) และฝึกออกเสียงผ่านไมโครโฟน
    *   กรองคำศัพท์ตามระดับ (A1, A2, B1, B2) และค้นหาคำศัพท์
    *   กด ⭐️ เพื่อบันทึกคำศัพท์โปรด
*   ✅ **ระบบจัดการสิ่งที่ต้องทำ (To-Do Today):**
    *   จดบันทึกและติดตามสิ่งที่ต้องทำในแต่ละวัน
    *   ติ๊กเพื่อขีดฆ่างานที่ทำเสร็จแล้ว หรือลบทิ้งได้อย่างง่ายดาย
*   💰 **กระเป๋าเงิน & บันทึกรายรับ-รายจ่าย (Finance Tracker & Monthly/Yearly Analytics):**
    *   บันทึกรายรับและรายจ่ายประจำวัน พร้อมเลือกระบุหมวดหมู่
    *   **ระบบสรุปรายเดือน & รายปี**: เลือกสลับดูสรุปยอดเงินคงเหลือ รายรับรวม รายจ่ายรวม ของแต่ละเดือน (เช่น กรกฎาคม 2569) หรือแต่ละปี (เช่น 2569)
    *   **วิเคราะห์แยกตามหมวดหมู่**: แสดงกราฟสัดส่วนรายจ่ายเปอร์เซ็นต์ (%) ในแต่ละหมวดหมู่ (อาหาร, เดินทาง, ช้อปปิ้ง ฯลฯ)
*   💧 **ตัวติดตามการดื่มน้ำ (Water Intake Tracker):**
    *   แสดงระดับน้ำและเป้าหมายการดื่มน้ำประจำวัน (2,000 ml)
    *   ปุ่มทางลัดเติมน้ำตามขนาดแก้ว (+200ml, +350ml, +500ml) พร้อม Wave Bar Animation
*   ⚡ **ติดตามนิสัยประจำวัน (Habit Tracker):**
    *   ตั้งเป้าหมายนิสัยที่อยากทำทุกวัน (เช่น อ่านหนังสือ, ออกกำลังกาย, นั่งสมาธิ)
    *   ระบบเช็กอินประจำวันพร้อมสะสม Streak นับจำนวนวันต่อเนื่อง
*   🎮 **โหมดทดสอบ (Quiz Mode):**
    *   เกมทายคำศัพท์ ทายความหมาย ทายจากการฟัง และพิมพ์คำศัพท์เพื่อทดสอบความจำ
*   🔥 **ระบบติดตามความคืบหน้า (Progress & Streaks):**
    *   นับจำนวนวันที่เข้าใช้งานต่อเนื่อง (Daily Streak)
*   🌙 **การตั้งค่า (Settings):**
    *   รองรับโหมดกลางคืน (Dark Mode) และ Auto-play Audio
*   💾 **จัดการฐานข้อมูลส่วนตัวในเครื่อง (Local Database Offline 100%):**
    *   ส่งออกและดาวน์โหลดไฟล์สำรองข้อมูล (`MYFEE_Backup_YYYY-MM-DD.json`) เก็บในเครื่องคอมพิวเตอร์/มือถือส่วนตัว (ไม่ต้องผ่าน Cloud)
    *   นำเข้าไฟล์สำรองเพื่อคืนค่าฐานข้อมูล (Restore Database) ได้ทันที
    *   แสดงขนาดของฐานข้อมูล (KB) และจำนวนรายการที่บันทึกไว้
*   📱 **รองรับ PWA (Progressive Web App):**
    *   สามารถติดตั้งลงบนหน้าจอโฮมมือถือ/คอมพิวเตอร์ และใช้งานออฟไลน์ได้ 100%

## ⚙️ การพิจารณาเลือกใช้ Framework (Tech Stack Evaluation)

| ทางเลือก | ข้อดี (Pros) | ข้อเสีย (Cons) | คำแนะนำสำหรับ MY FEE |
|---|---|---|---|
| **Vanilla JS (ปัจจุบัน)** | • โหลดเร็วที่สุด (Zero Overhead)<br>• ใช้งานได้ทันทีเพียงเปิด `index.html`<br>• ไม่ต้องมี Node.js หรือสั่ง Build<br>• ทำ PWA & Offline Caching ง่ายมาก | • หากแอปมีขนาดใหญ่มาก การจัดการ DOM ด้วยตัวเองอาจยาวขึ้น | **🟢 แนะนำใช้งานต่อสำหรับปัจจุบัน**<br>เนื่องจากโครงสร้างโปรเจกต์ปัจจุบันถูกจัดเป็น Modular ES6 (`js/core/`, `js/features/`) ที่ทำงานได้เร็วและเบาที่สุดแล้ว |
| **Vite + Vue 3 / Svelte** | • Reactive State อัปเดต UI อัตโนมัติ<br>• เขียน Reusable UI Components ง่าย<br>• มีระบบ Bundling ที่ดี | • ต้องมี Node.js ในการพัฒนา<br>• ต้อง Refactor โค้ดใหม่ทั้งหมด | **🟡 เหมาะสำหรับอนาคต**<br>หากต้องการขยายระบบให้มี 10+ ฟีเจอร์ที่ซับซ้อนมาก และพร้อมใช้งาน Node.js build system |
| **React / Next.js** | • Ecosystem และ Library กว้างขวาง | • ขนาดไฟล์ Bundle ใหญ่ขึ้น<br>• ซับซ้อนเกินความจำเป็นสำหรับ PWA ออฟไลน์ขนาดเบา | **🔴 ยังไม่จำเป็น** |

### 📱 ความเข้าใจเรื่องการใช้งานบนมือถือและการออฟไลน์ (Mobile & Offline PWA)

* **คำถาม**: หากต้องการโหลดบนมือถือและใช้งานแบบออฟไลน์ จำเป็นต้องใช้ React / Next.js หรือไม่?
* **คำตอบ**: **ไม่จำเป็นเลย** (และ Vanilla JS ปัจจุบันทำงานได้ดีกว่าสำหรับเป้าหมายนี้)
  * การทำให้แอปใช้งานบนมือถือ (ปุ่ม "Add to Home Screen") และเปิดเล่นแบบ**ออฟไลน์ (Offline)** 100% ควบคุมด้วยมาตรฐาน **PWA (`manifest.json` + `service-worker.js`)** ซึ่งทำงานร่วมกับ HTML/JS ทั่วไปได้ทันที ไม่ต้องพึ่งพากรอบทำงานของ React หรือ Next.js
  * **Vanilla JS** มีขนาดไฟล์รวมไม่ถึง 1 MB จึงโหลดบนมือถือเร็วที่สุด เปิดติดใน 0.1 วินาที ไม่กินแรมและแบตเตอรี่มือถือ
