# MY FEE 📚✨

**MY FEE** คือแอปพลิเคชันผู้ช่วยส่วนตัวในชีวิตประจำวัน (Personal All-in-One Life Companion) ที่สร้างขึ้นมาเพื่อตอบโจทย์การใช้งานของตัวเองเป็นหลัก ทำงานแบบ Single Page Application (SPA) ความเร็วสูง จัดเก็บข้อมูลทั้งหมดในเครื่องผ่าน LocalStorage และรองรับการใช้งานออฟไลน์ (PWA) 100%

---

## 🌟 ฟีเจอร์ปัจจุบัน (Current Features)

*   📊 **ศูนย์รวมภาพรวมชีวิต (Life Dashboard & Analytics):**
    *   หน้าแรกแบบ Hub รวมการ์ดสรุปสถานะประจำวัน: สถิติ Flashcards, งาน To-Do, ปริมาณการดื่มน้ำ, ยอดใช้จ่ายประจำวัน และการทำนิสัยประจำวัน
    *   ระบบ Quick Launcher เข้าถึงทุกเมนูได้ในสัมผัสเดียว
*   📖 **ระบบเรียนรู้คำศัพท์ (Flashcards):**
    *   เรียนรู้คำศัพท์ภาษาอังกฤษพร้อมคำอ่าน (IPA) และชนิดของคำ (Part of Speech)
    *   พลิกการ์ด 3D เพื่อดูคำแปลภาษาไทยและประโยคตัวอย่าง
    *   มีระบบออกเสียงคำศัพท์ (Text-to-Speech) และฝึกออกเสียงผ่านไมโครโฟน
    *   กรองคำศัพท์ตามระดับ (A1, A2, B1, B2) และค้นหาคำศัพท์
    *   กด ⭐️ เพื่อบันทึกคำศัพท์โปรด
*   ✅ **ระบบจัดการสิ่งที่ต้องทำ (To-Do Today):**
    *   จดบันทึกและติดตามสิ่งที่ต้องทำในแต่ละวัน
    *   ติ๊กเพื่อขีดฆ่างานที่ทำเสร็จแล้ว หรือลบทิ้งได้อย่างง่ายดาย
*   💰 **กระเป๋าเงิน & บันทึกรายรับ-รายจ่าย (Finance Tracker & Monthly/Yearly Analytics):**
    *   บันทึกรายรับและรายจ่ายประจำวัน พร้อมเลือกระบุหมวดหมู่
    *   **ระบบสรุปรายเดือน & รายปี**: เลือกสลับดูสรุปยอดเงินคงเหลือ รายรับรวม รายจ่ายรวม ของแต่ละเดือน (เช่น กรกฎาคม 2569) หรือแต่ละปี (เช่น 2569)
    *   **วิเคราะห์แยกตามหมวดหมู่**: แสดงกราฟสัดส่วนรายจ่ายเปอร์เซ็นต์ (%) ในแต่ละหมวดหมู่ (อาหาร, เดินทาง, ช้อปปิ้ง ฯลฯ)
*   ⚡ **ติดตามนิสัยประจำวัน (Habit Tracker):**
    *   ตั้งเป้าหมายนิสัยที่อยากทำทุกวัน (เช่น อ่านหนังสือ, ออกกำลังกาย, นั่งสมาธิ)
    *   ระบบเช็กอินประจำวันพร้อมสะสม Streak นับจำนวนวันต่อเนื่อง
*   🎮 **โหมดทดสอบ (Quiz Mode):**
    *   เกมทายคำศัพท์ ทายความหมาย ทายจากการฟัง และพิมพ์คำศัพท์เพื่อทดสอบความจำ
*   🔥 **ระบบติดตามความคืบหน้า (Progress & Streaks):**
    *   นับจำนวนวันที่เข้าใช้งานต่อเนื่อง (Daily Streak)
*   🌙 **การตั้งค่า (Settings):**
    *   รองรับโหมดกลางคืน (Dark Mode) และ Auto-play Audio
*   💾 **จัดการฐานข้อมูลส่วนตัวในเครื่อง (Local Database Offline 100%):**
    *   ส่งออกและดาวน์โหลดไฟล์สำรองข้อมูล (`MYFEE_Backup_YYYY-MM-DD.json`) เก็บในเครื่องคอมพิวเตอร์/มือถือส่วนตัว (ไม่ต้องผ่าน Cloud)
    *   นำเข้าไฟล์สำรองเพื่อคืนค่าฐานข้อมูล (Restore Database) ได้ทันที
    *   แสดงขนาดของฐานข้อมูล (KB) และจำนวนรายการที่บันทึกไว้
*   📱 **รองรับ PWA (Progressive Web App):**
    *   สามารถติดตั้งลงบนหน้าจอโฮมมือถือ/คอมพิวเตอร์ และใช้งานออฟไลน์ได้ 100%

## ⚙️ การพิจารณาเลือกใช้ Framework (Tech Stack Evaluation)

| ทางเลือก | ข้อดี (Pros) | ข้อเสีย (Cons) | คำแนะนำสำหรับ MY FEE |
|---|---|---|---|
| **Vanilla JS (ปัจจุบัน)** | • โหลดเร็วที่สุด (Zero Overhead)<br>• ใช้งานได้ทันทีเพียงเปิด `index.html`<br>• ไม่ต้องมี Node.js หรือสั่ง Build<br>• ทำ PWA & Offline Caching ง่ายมาก | • หากแอปมีขนาดใหญ่มาก การจัดการ DOM ด้วยตัวเองอาจยาวขึ้น | **🟢 แนะนำใช้งานต่อสำหรับปัจจุบัน**<br>เนื่องจากโครงสร้างโปรเจกต์ปัจจุบันถูกจัดเป็น Modular ES6 (`js/core/`, `js/features/`) ที่ทำงานได้เร็วและเบาที่สุดแล้ว |
| **Vite + Vue 3 / Svelte** | • Reactive State อัปเดต UI อัตโนมัติ<br>• เขียน Reusable UI Components ง่าย<br>• มีระบบ Bundling ที่ดี | • ต้องมี Node.js ในการพัฒนา<br>• ต้อง Refactor โค้ดใหม่ทั้งหมด | **🟡 เหมาะสำหรับอนาคต**<br>หากต้องการขยายระบบให้มี 10+ ฟีเจอร์ที่ซับซ้อนมาก และพร้อมใช้งาน Node.js build system |
| **React / Next.js** | • Ecosystem และ Library กว้างขวาง | • ขนาดไฟล์ Bundle ใหญ่ขึ้น<br>• ซับซ้อนเกินความจำเป็นสำหรับ PWA ออฟไลน์ขนาดเบา | **🔴 ยังไม่จำเป็น** |

### 📱 ความเข้าใจเรื่องการใช้งานบนมือถือและการออฟไลน์ (Mobile & Offline PWA)

* **คำถาม**: หากต้องการโหลดบนมือถือและใช้งานแบบออฟไลน์ จำเป็นต้องใช้ React / Next.js หรือไม่?
* **คำตอบ**: **ไม่จำเป็นเลย** (และ Vanilla JS ปัจจุบันทำงานได้ดีกว่าสำหรับเป้าหมายนี้)
  * การทำให้แอปใช้งานบนมือถือ (ปุ่ม "Add to Home Screen") และเปิดเล่นแบบ**ออฟไลน์ (Offline)** 100% ควบคุมด้วยมาตรฐาน **PWA (`manifest.json` + `service-worker.js`)** ซึ่งทำงานร่วมกับ HTML/JS ทั่วไปได้ทันที ไม่ต้องพึ่งพากรอบทำงานของ React หรือ Next.js
  * **Vanilla JS** มีขนาดไฟล์รวมไม่ถึง 1 MB จึงโหลดบนมือถือเร็วที่สุด เปิดติดใน 0.1 วินาที ไม่กินแรมและแบตเตอรี่มือถือ

## ⭐ แผนยกระดับฟีเจอร์ปัจจุบันสู่ประสิทธิภาพสูงสุด (Max Utility Optimization Plan)

เพื่อไม่ให้ต้องคอยกลับมาเพิ่มฟีเจอร์จุกจิกในภายหลัง เราจะมุ่งเป้าให้ **"6 ฟีเจอร์ที่มีอยู่แล้วในปัจจุบัน"** ทำงานได้อย่างครบวงจร ฉลาด มีประโยชน์ และตอบโจทย์การใช้งานจริงในทุกวันอย่างถึงขีดสุด โดยมีแผนการยกระดับดังนี้:

### ✅ 1. ระบบจัดการงาน To-Do -> *Smart & Prioritized Workspace*
* **🎯 ระบบระดับความสำคัญ (Priority Level)**: ติดป้าย 🔴 `สำคัญมาก (High)` 🟡 `ปกติ (Med)` 🔵 `เวลาว่าง (Low)` เพื่อให้โฟกัสงานที่ส่งผลต่อชีวิตจริงก่อนเสมอ
* **🏷️ หมวดหมู่งาน (Tags / Category)**: จัดกลุ่มงาน เช่น `🏢 การงาน/เรียน`, `🏠 บ้าน`, `💪 พัฒนาตัวเอง` และกรองดูเฉพาะกลุ่มที่ต้องการได้ง่ายๆ
* **🤖 จัดเรียงลำดับอัจฉริยะ (Smart Sorting)**: งานสำคัญและงานของ "วันนี้" จะถูกดันขึ้นบนสุดอัตโนมัติ งานที่ติ๊กเสร็จแล้วจะถูกย้ายลงล่างสุดหรือแยกเก็บเข้าปูมประวัติ (Archive) เพื่อความสะอาดตา
* **📜 ดูประวัติงานสำเร็จย้อนหลัง (Completed History Archive)**: สามารถย้อนดูได้ว่า 7 วันที่ผ่านมาเราทำภารกิจอะไรสำเร็จไปแล้วบ้าง สร้างความภูมิใจ (Dopamine & Motivation)

### 💰 2. กระเป๋าเงิน (Finance Tracker) -> *Complete Financial Companion*
* **🚨 ระบบจำกัดงบประมาณ (Daily / Monthly Budget Alert)**: กำหนด "งบใช้จ่ายสูงสุดรายวัน" (เช่น วันละ ฿300) หรือรายเดือน ถ้ารายจ่ายใกล้ครบหรือเกินงบ ตัวเลขในหน้า Dashboard จะเปลี่ยนเป็นสีแดง 🔴 หรือแจ้งเตือน เพื่อช่วยคุมเงินได้จริง
* **🔍 ระบบค้นหาและกรอง (Search & Category Filters)**: พิมพ์คำค้นหา (เช่น "ค่าไฟ", "ค่าเน็ต") หรือกดแท็บ กรองดูรายการเฉพาะหมวดหมู่ "อาหาร 🍛", "เดินทาง 🚕", "ช้อปปิ้ง 🛍️" เพื่อวิเคราะห์ว่าเงินจมไปกับอะไรที่สุด
* **📤 ส่งออกไฟล์นามสกุล CSV/Excel**: สามารถกด Export ข้อมูลการเงินออกมาเป็นไฟล์ `.CSV` เพื่อเปิดใน Microsoft Excel หรือ Google Sheets สำหรับนำไปสรุปงบจริงจังหรือคำนวณยื่นภาษีได้ทันที!

### ⚡ 3. ตัวติดตามนิสัย & กิจวัตรประจำวัน (Habit & Daily Routine Tracker) -> *Visual Streak Heatmap*
* **🟢 แถบสีแสดงสถิติดั้งเดิม 7 วันล่าสุด (Weekly Visual Heatmap)**: บนการ์ดนิสัยแต่ละรายการ จะมีวงกลมแสดงผลสถานะ 7 วันที่ผ่านมา (เช่น 🟢🟢⚪🟢🟢🟢🟢) ให้มองเห็นความต่อเนื่องได้ทันทีแบบแอปชั้นนำ (Notion/GitHub Heatmap)
* **🏆 บันทึกสถิติสูงสุด (Best Streak & Consistency Rate)**: บันทึกสถิติสตรีคสูงสุดที่เคยทำได้ และแสดงอัตราความสำเร็จโดยรวมเป็น % (เช่น ทำสำเร็จคิดเป็น 85% ของเดือนนี้)
* **☀️ แบ่งหมวดกิจวัตรประจำวัน (Daily Routine Builder)**: เปลี่ยนเป้าหมายธรรมดาให้เป็นตารางกิจวัตร โดยจัดกลุ่มตามเวลาชัดเจน: 🌅 กิจวัตรยามเช้า (Morning Routine) / ☀️ กลางวัน (Afternoon) / 🌙 ก่อนนอน (Evening Routine) เพื่อให้ทำตามได้อย่างเป็นระบบ

### 📖 4. ระบบเรียนรู้คำศัพท์ (Flashcards & Quiz) -> *Personalized Knowledge Base*
* **🧠 ทบทวนแบบชาญฉลาด (Smart Leitner / Spaced Repetition)**: ระบบช่วยจดจำ! คำศัพท์ไหนที่ "กดดูแปลภาษาไทยบ่อย" หรือ "ตอบผิดในโหมด Quiz" จะถูกแทรกป้าย ⚠️ *ต้องทบทวน (Needs Review)* และจัดโหลดคำนั้นขึ้นมาให้หัดซ้ำบ่อยๆ โดยอัตโนมัติ
* **✏️ เพิ่มคำศัพท์ของตัวเองได้ (Custom Words Creator)**: ปุ่ม `+ เพิ่มคำศัพท์ส่วนตัว` ให้ผู้ใช้เก็บคำศัพท์ที่เพิ่งเรียนรู้จากซีรีส์หรือจากการทำงานลงในฐานข้อมูลเครื่องของตัวเองได้ทันที (เก็บใน LocalStorage)

### 📊 5. ศูนย์รวมภาพรวม (Life Dashboard) -> *Actionable Command Center*
* **💬 คำทักทายและรายงานสรุปประจำวัน (Daily Status Summary Text)**: ข้อความวิเคราะห์ข้อมูลอัจฉริยะในหน้าแรก เช่น *“🌅 สวัสดีตอนเช้า! วันนี้มีภารกิจสำคัญรออยู่ 3 งาน และคุณยังมีโควตาใช้จ่ายตามงบได้อีก ฿250”*
* **🔴 ป้ายแจ้งเตือนเมนูที่ต้องทำ (Notification Badges)**: มีจุดแจ้งเตือนตัวเลขสีแดงบนเมนูใน Quick Launcher หาก "วันนี้ยังไม่ได้เช็กอิน Habit" หรือ "มีคำศัพท์รอให้ทบทวน"
* **⏱️ วิดเจ็ตคูลดาวน์ & โฟกัส (Cooldown & Focus Widget)**: เพิ่มวิดเจ็ตจับเวลาหน้า Dashboard สำหรับกำหนดช่วงเวลาทำงาน (Focus) และเวลาพักเบรกผ่อนคลายสมอง (Cooldown) แบบ Pomodoro หรือตั้งเวลานับถอยหลังพักสายตา
* **🎛️ ปรับแต่งการแสดงผลวิดเจ็ต (Custom Layout Toggle)**: ตัวเลือกเปิด-ปิด หรือเรียงลำดับวิดเจ็ตในหน้า Dashboard เพื่อให้อยู่ในมุมมองที่ตรงกับไลฟ์สไตล์ของผู้ใช้งานมากที่สุด

### 💾 6. จัดการฐานข้อมูล (Local Database) -> *Automated Safe-guard*
* **⏰ แจ้งเตือนการสำรองข้อมูลอัตโนมัติ (Auto-Backup Reminder)**: หากใช้งานแอปผ่านไป 14 วันโดยไม่ได้กดส่งออก (Export) ไฟล์ Backup เลย ระบบจะแสดงป้ายเตือนนุ่มนวลเพื่อรณรงค์ให้สำรองไฟล์ ป้องกันข้อมูลหายในกรณีเครื่องเสียหรือเบราว์เซอร์ล้างความจำ
