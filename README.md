# My Fee 📚✨

**My Fee** คือแอปพลิเคชันส่วนตัวที่สร้างขึ้นมาเพื่อใช้งานในชีวิตประจำวัน เน้นความสะดวกสบายและตอบโจทย์การใช้งานของตัวเองเป็นหลัก โดยฟีเจอร์ต่างๆ ภายในแอปจะถูกพัฒนาและเพิ่มเติมเข้าไปเรื่อยๆ ตามความต้องการใช้งาน ณ ขณะนั้น (อยากเพิ่มอะไรก็เพิ่ม!)

## 🌟 ฟีเจอร์ปัจจุบัน (Current Features)

แอปพลิเคชันถูกออกแบบให้เป็น Single Page Application (SPA) ที่ทำงานได้รวดเร็ว โดยมีการแบ่งสัดส่วนการทำงาน (Modular) อย่างเป็นระเบียบ:

*   📖 **ระบบเรียนรู้คำศัพท์ (Flashcards):**
    *   เรียนรู้คำศัพท์ภาษาอังกฤษพร้อมคำอ่าน (IPA) และชนิดของคำ (Part of Speech)
    *   พลิกการ์ดเพื่อดูคำแปลภาษาไทยและประโยคตัวอย่าง
    *   มีระบบออกเสียงคำศัพท์ (Text-to-Speech) และฝึกออกเสียงผ่านไมโครโฟน
    *   กรองคำศัพท์ตามระดับ (A1, A2, B1, B2), ตัวอักษร, หรือค้นหาคำศัพท์ที่ต้องการ
    *   กด ⭐️ เพื่อบันทึกคำศัพท์ที่ชอบได้
*   ✅ **ระบบจัดการสิ่งที่ต้องทำ (To-Do Today):**
    *   จดบันทึกและติดตามสิ่งที่ต้องทำในแต่ละวัน
    *   ติ๊กเพื่อขีดฆ่างานที่ทำเสร็จแล้ว หรือลบทิ้งได้อย่างง่ายดาย
*   🎮 **โหมดทดสอบ (Quiz Mode):**
    *   เกมทายคำศัพท์ ทายความหมาย ทายจากการฟัง และพิมพ์คำศัพท์เพื่อทดสอบความจำ
*   🔥 **ระบบติดตามความคืบหน้า (Progress & Streaks):**
    *   ติดตามจำนวนคำที่เรียนไปแล้ว และนับจำนวนวันที่เข้าเรียนอย่างต่อเนื่อง (Streak)
*   🌙 **การตั้งค่า (Settings):**
    *   รองรับโหมดกลางคืน (Dark Mode) เพื่อความสบายตา
    *   รองรับการเล่นเสียงอัตโนมัติ (Auto-play Audio) เมื่อพลิกการ์ด

## 🛠 โครงสร้างโปรเจกต์ (Project Structure)

โปรเจกต์ถูกเขียนด้วย Vanilla JavaScript, HTML5, และ Tailwind CSS โดยไม่พึ่งพา Framework ใหญ่ๆ เพื่อความรวดเร็วและปรับแต่งได้ง่าย โค้ดถูกจัดกลุ่มอย่างเป็นระเบียบ ดังนี้:

```text
📁 Myfee/
├── 📄 index.html        # หน้าจอหลักของแอป
├── 📄 style.css         # ไฟล์ปรับแต่ง CSS เพิ่มเติม
├── 📄 data.js           # ฐานข้อมูลคำศัพท์ (window.flashcardsData)
└── 📁 js/
    ├── 📄 main.js       # ไฟล์เริ่มการทำงานและจัดการ Event หลัก
    ├── 📁 core/         # ระบบหลักของแอป
    │   ├── state.js     # จัดการข้อมูล State และ LocalStorage
    │   ├── dom.js       # จัดการเรื่อง HTML Elements
    │   ├── navigation.js# ระบบเปลี่ยนหน้าจอ (Routing)
    │   └── settings.js  # จัดการตั้งค่า Streak และ Dark Mode
    ├── 📁 flashcards/   # ระบบคำศัพท์
    │   ├── flashcards.js# ระบบการ์ด, ตัวกรอง, เสียงอ่าน
    │   └── quiz.js      # ระบบแบบทดสอบ
    └── 📁 todo/         # ระบบ To-Do list
        └── todo.js      # ระบบเพิ่ม/ลบ/อัปเดตงาน
```

## 🚀 การใช้งาน (How to use)

1. ดาวน์โหลดหรือ Clone โปรเจกต์นี้
2. เปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์
3. สามารถใช้งานได้ทันที (ข้อมูลทั้งหมดถูกบันทึกแบบออฟไลน์ผ่าน `LocalStorage` ของเบราว์เซอร์)

> **Note:** แอปนี้พัฒนาขึ้นเพื่อใช้งานส่วนตัว (Personal Use) ฟังก์ชันต่างๆ จะถูกเพิ่มเข้ามาเรื่อยๆ ในอนาคต! 🚀
